Функции для работы с двухсвязным упорядоченным списком собраны в
динамическую библиотеку libcontactlist.so. Она остаётся отдельным файлом
и нужна программе во время запуска.

Функции из phonebook.c компилируются с параметром -fPIC, после чего
при помощи параметра -shared создаётся динамическая библиотека.
Функция main и меню программы остались отдельно в main.c и в библиотеку
не входят.

Основная программа и юнит-тесты связываются с libcontactlist.so.
При запуске используется LD_LIBRARY_PATH=., чтобы программа могла найти
динамическую библиотеку в текущем каталоге.

Программа собирается командой make и запускается командой make run.
Тесты запускаются командой make test, а результаты сборки удаляются
командой make clean.
