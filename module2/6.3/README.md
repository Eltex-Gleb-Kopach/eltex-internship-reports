Каждая операция калькулятора вынесена в отдельную динамическую
библиотеку. В каждой библиотеке находится одна функция operation с общей
для всех операций сигнатурой.

Исходники операций находятся в каталоге plugin_sources. При сборке они
компилируются с параметрами -fPIC и -shared, после чего в каталоге plugins
создаются библиотеки libadd.so, libsubtract.so, libmultiply.so и
libdivide.so.

При запуске программа просматривает каталог plugins, открывает найденные
библиотеки при помощи dlopen и получает адрес функции operation через
dlsym. Названия команд формируются из имён библиотек, поэтому меню зависит
от найденных в каталоге плагинов. Перед завершением программы все
библиотеки закрываются при помощи dlclose.

Программа собирается командой make и запускается командой ./calculator.
Тесты запускаются командой make test, а результаты сборки удаляются
командой make clean.
