## Структура проекта

main.c — точка входа. Проверяет аргументы и имя участника, затем запускает чат.

udp_chat.c — создание и настройка UDP-сокета, широковещательная отправка,
приём сообщений, работа poll(), обработка протокола и завершение по SIGINT.

udp_chat.h — общие константы и объявление функции запуска чата.

Makefile — сборка программы, запуск тестов и удаление файлов сборки.

tests/test.sh — автоматическая проверка аргументов, обмена сообщениями и
завершения программы.

## Сборка

```bash
make
```

Будет создан исполняемый файл udp_chat.

## Запуск

Программа принимает один аргумент — имя участника:

```bash
./udp_chat Gleb
```

## Тестирование

```bash
make test
```

## Очистка файлов сборки

```bash
make clean
```
