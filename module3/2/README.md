Назначение файлов

main.c — точка входа в программу. Проверяет аргументы запуска, определяет роль процесса по ключу -b, -p или -s и вызывает функцию брокера, издателя или подписчика.

broker.c — содержит основную логику брокера. Брокер создаёт очередь System V, принимает команды участников, хранит подписки и PID издателей, пересылает публикации подходящим подписчикам и управляет завершением всех процессов.

broker.h — содержит объявление функции запуска брокера run_broker().

publisher.c — содержит логику издателя. Издатель подключается к очереди, регистрирует свой PID у брокера, читает сообщения пользователя, отправляет публикации выбранной темы и сообщает о своём завершении.

publisher.h — содержит объявление функции запуска издателя run_publisher().

subscriber.c — содержит логику подписчика. Подписчик подключается к очереди, отправляет команды подписки на темы, получает предназначенные ему публикации и перед завершением отправляет команды отписки.

subscriber.h — содержит объявление функции запуска подписчика run_subscriber().

message_queue.c — содержит функции работы с очередью сообщений System V: создание, поиск, удаление, получение количества оставшихся сообщений, отправку и получение сообщений в блокирующем и неблокирующем режимах.

message_queue.h — содержит объявления функций работы с очередью сообщений.

protocol.h — описывает общий формат сообщений. В нём находятся размеры темы и текста, тип сообщений для брокера и структура queue_message, передаваемая через очередь.

subscriptions.c — управляет динамическим списком подписок брокера. Каждая запись связывает PID подписчика с одной темой. Файл содержит функции добавления, удаления и освобождения подписок.

subscriptions.h — содержит структуры подписки и списка подписок, а также объявления функций управления этим списком.

publisher_list.c — управляет динамическим списком PID работающих издателей. Содержит функции добавления, удаления и освобождения списка.

publisher_list.h — содержит структуру списка издателей и объявления функций работы с ним.

signal_control.c — содержит общий обработчик SIGINT и флаг завершения, используемый брокером, издателем и подписчиком.

signal_control.h — содержит объявления функций настройки обработчика SIGINT и проверки флага завершения.

Makefile — собирает программу pubsub, запускает тестовый скрипт и удаляет исполняемый файл командой make clean.

tests/test.sh — автоматически проверяет неправильные аргументы, запуск участников без брокера, защиту от второго брокера, маршрутизацию по темам, отправку нескольких публикаций, завершение процессов, удаление и недоступность очереди, таймаут и ожидание освобождения очереди.

pubsub — исполняемый файл, создаваемый командой make. Он не является исходным файлом программы.
