# Задание 4. Производитель и потребители

Программа реализует модель «Производитель–Потребители» с использованием
разделяемой памяти и семафора System V.

Производитель создаёт в разделяемой памяти односвязный список блоков со
случайными числами. Потребители находят минимальное и максимальное значения в
блоках и отмечают обработанные блоки. Можно одновременно запустить несколько
потребителей.

## Структура проекта

`main.c` — точка входа и выбор режима работы программы.

`producer.c` и `producer.h` — создание общих ресурсов, генерация блоков и
ожидание потребителей.

`consumer.c` и `consumer.h` — подключение к общим ресурсам и обработка блоков.

`shared_data.h` — общие структуры, размер памяти и ключи IPC.

`semaphore_control.c` и `semaphore_control.h` — работа с семафором System V.

`Makefile` — сборка программы, запуск тестов и удаление файлов сборки.

`tests/test.sh` — автоматическая проверка основных режимов программы.

## Сборка

```bash
make
```

## Запуск

Сначала в одном терминале необходимо запустить производителя:

```bash
./shared_list producer
```

После этого в другом терминале можно запустить одного или нескольких
потребителей:

```bash
./shared_list consumer
```

Производитель заполнит разделяемую память, дождётся обработки всех блоков и
отключения потребителей, после чего удалит разделяемую память и семафор.

## Тестирование

```bash
make test
```

Тестовый скрипт проверяет обработку неправильных аргументов, запуск потребителя
без производителя, защиту от второго производителя, работу одного и двух
потребителей и удаление IPC-ресурсов.

## Очистка файлов сборки

```bash
make clean
```
